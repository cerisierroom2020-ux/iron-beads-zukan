# アイロンビーズ図案ずかん

`index.html` だけで動くアプリです。ダブルクリックでブラウザが開きます。

## できること

- **ずかん** … 内蔵50図案を一覧→クリックで拡大。
  5マスごとのガイド線、必要なビーズの色と個数、拡大縮小、印刷。
- **つくる** … 4〜58マスの好きなサイズで自作。ペン／消しゴム／スポイト／ぬりつぶし、もどす、保存。
- **しゃしんから** … 画像をドラッグ&ドロップ、または Ctrl+V ではりつけ → ビーズ24色に自動変換。
  - サイズプリセット（16/24/29/40）、使う色の数、白背景の自動ぬき
  - **黒でふちどり**（キャラクター向け。輪郭が出てぐっとそれらしくなる）
  - 細かいノイズ（輪郭のギザギザ）は自動で周囲の色に吸収
  - そのまま「つくる」タブで手直しできる
- **データ** … 自作図案のJSON書き出し／読み込み。

## キャラクターの図案について

「キャラ」カテゴリに入っているのは、**特定の権利者がいないモチーフ**だけです。

- 日本の伝承・縁起物：だるま・おに・かっぱ・まねきねこ・てるてるぼうず
- 一般名詞としてのキャラ：ゆきだるま・サンタ・トナカイ・まじょ・にんじゃ・かいぞく・うちゅうじん・ドラゴン・がいこつ
- 完全オリジナル：ロボット・ゆにこーん・おばけ

ちいかわ・ディズニーなど**既存のキャラクターの図案データは含めていません**
（キャラクターデザインの複製にあたるため）。
作りたいときは「しゃしんから」タブに手持ちの画像を入れて変換してください。
変換した図案は家庭内で楽しむ範囲にとどめ、配布・販売はしないでください。

## 保存について

自作図案はブラウザの localStorage に保存されます（端末ごと）。
ファイルを直接開く方式だと保存できないブラウザがあります。その場合は画面上に注意が出るので、
「データ」タブの書き出しでバックアップするか、下記のようにサーバー経由で開いてください。

```bash
python -m http.server 8777 --directory beads
```

→ ブラウザで http://localhost:8777 を開く
